# Jiahao Hui's academic homepage

Static personal homepage for GitHub Pages.

## Publish

1. Create a public GitHub repository named `L4HeyXiao.github.io`.
2. Push the contents of this directory to the repository's `main` branch.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, `main`, and `/(root)`.
4. Visit <https://l4heyxiao.github.io/>.
